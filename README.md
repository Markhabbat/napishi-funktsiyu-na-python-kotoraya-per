# napishi-funktsiyu-na-python-kotoraya-per

Напиши функцию на Python которая переворачивает строку

## План

# 1. ПОНИМАНИЕ ЗАДАЧИ

Необходимо написать функцию на Python, которая переворачивает строку (разворачивает её в обратном порядке). Задача простая, но нужно предусмотреть разные подходы и обработку ошибок.

---

# 2. ТЕХНИЧЕСКИЙ ПЛАН

## Шаг 1: Определить требования
- Основная функциональность: развернуть строку в обратном порядке
- Обработка edge cases (пустые строки, None, Unicode)
- Валидация входных данных
- Документирование с примерами

## Шаг 2: Реализовать несколько подходов
1. **Slice подход** - самый Pythonic (рекомендуется)
2. **Reversed() функция** - с итератором
3. **Рекурсивный подход** - для демонстрации
4. **Iterative подход** - с циклом

## Шаг 3: Добавить валидацию и обработку ошибок
- Проверка типа входного значения
- Обработка None
- Поддержка Unicode символов

- Тестирование базовых случаев
- Тестирование edge cases
- Тестирование ошибок
